# Guides

How to do each thing in the console, step by step, with a picture of
each screen as you'll see it.

- [Starting a group](starting-a-group.md): signing in, starting a group,
  and giving it a picture and words.
- [Rules and roles](rules-and-roles.md): writing the group's rules,
  making roles, and giving them to members.
- [Moderating](moderating.md): what members report, labelling and taking
  down, and removing someone.
- [Signing in as a group in another app](signing-in-as-a-group.md): an
  app password, so a bot or another app can post as the group.
- [Adding a recovery key](recovery-keys.md): a key you hold, so you can
  take the group back or move it without this host.

For why the host works as it does, see the [design](../design/README.md)
pages. For every command, see the [reference](../reference/cli.md).
